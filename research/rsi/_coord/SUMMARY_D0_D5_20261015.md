## 2. D1 — context/anchor 双轴与布局重排（regroup）

**研究问题**：两轴 (C,A) 分布对 block drafter 成本是否有额外解释力；能否用物理重排（regroup）把 padding 槽位/块级冗余去掉。

### 2.1 做了什么（阶段）
- Wave-1：审计 anchor 语义（A 由物理批最长答案决定、随机锚受批形状影响→实验须冻结 anchor 表重放）；两轴分布探针；建 W1/W2/W3 特征 store（offline）。
- Wave-2：regroup 机制开发（k=4；canonical/split/token/cost/grid 臂；≥3 交替；100–200 更新）+ 同路径 parity oracle（loss/分项/梯度/update；identity 控制 ≤2.3e-7）。
- R3/R4：k2/k4 全矩阵；sub_batch=1 边界 A/B（预注册判 ≥1.135）。
- 组合与质量：D4×D1 在线 2×2（8 腿）→ fp32_weights 单因子隔离对照 → held-out 质量轴 d1-006（band-first：先 canonical 42/43 建带，再 regroup 配对）→ 机制归因 d1-007（M1 五腿、每腿只变一个旋钮）。

### 2.2 结果
- **工程（C0 逐值重算）**：wave-2 6/6 rc=0；grid 配对 step 加速均值 **1.135×/1.133×**（W3/MIX）、580/600 批胜、parity b0/50/100 ✓；峰值显存 **−57%**（W3 b16 43.59→14.32 GiB；**b24 canonical OOM 5/5 → cost 14.41 GiB 5/5 可跑**；MIX b16 27.74→9.83 GiB）。
- R4 边界：W3 1.1296 / MIX 1.0199 < 1.135 → **负分支关闭**（`d1-005-c0`）；cross-check `3e29244` PASS（建议 a 采纳 → `192554a`）。
- **在线数值（2×2）**：W3 cell F1-as-registered **FAIL**（max 1.2475e-2@11；门 7.5e-3；17/100 超门）→ `cache×regroup` 组合暂禁；MIX cell 全过；交互 bit-0；隔离臂 F1B 亦 **FAIL**（2.2727e-2@11）→ 阻断加深（在线分组本身超带）。
- **质量轴（d1-006，冻结带 band_AL=1.8152128e-3 / band_acc=2.7917163e-4）**：regroup vs canonical 两 seed×两指标全出带——s42 **1.80×/1.69×**、s43 **4.86×/4.63×** → **FAIL**；绝对量级小（AL 相对 −0.28%/−0.76%），但门预注册、不事后放宽；「质量中性」声明不成立；长训练 GO 阻断项成立。
- **归因（d1-007）**：M1 在 **P1 控制腿**（identity 分组 + auto dtype，仅开启 machinery）即出带 **2.59×/2.47×** → 按冻结停止规则停 M1（未跑 P2–P6），交 bug report #01。

### 2.3 bug report #01 的结论（D1 取证，待 C0 裁定）
- 起点位一致：step 1–2 `grad_norm` 与 canon **逐位相同**；分歧自 step 3 起（≈7.0e-3，与 §9.1 oracle grad 界 ≤6.5e-3 同类）；早期=噪声带内波动→逐步放大，无阶跃/RNG 错位形态。
- **代码级缝**（即使恒等分组，regroup 路径≠shipped 数值路径；数学等价、bf16 归约类不等价）：① 损失归约（逐行缩放求和 vs 全局单次除法）；② 前向宽度裁剪（≈1k vs shipped 2048）；③ 逐组 backward 累加顺序。
- 含义：200 步动力学把 ≤1e-7–7e-3/步扰动放大为 2.6–4.9× band 漂移（machinery 基线分量≈总效应的 0.4–0.5×）→ d1-006 的结论需下修"layout 语义伤质量"权重；H4 假设（扰动在 N=200 内保持带内）被控制腿证伪。
- 待 C0 裁定三选：**A**=identity 位一致修复（仅治控制腿）；**B**=重基口径（为 machinery 自身建带）；**C**=并入数值阻断叙（当前证据支持度最高）。

## 3. D2 — 重叠 anchor 的 teacher 分布去重（ρ）

**研究问题**：N/U 重复（同一 teacher 条件分布被重叠 anchor 块重复投影）与 teacher/head/loss 占比是否可测且可观。

### 3.1 结果
- ρ 实测：canonical 配置（na=256, bs=8）**ρ 中位 6.83**（bs=16→14.17）；随 na 缩小而降（1.90 / 1.17 反例）；去重键=(batch, source position)，实现精确等价（CPU oracle 12/12，C0 复跑）。
- 收益：JetSpec mb4 计算步 **−12.4ms（−3.0%）**；DFly recipe mb4 **−33ms（−5.6%）**；显存不变（buffer 190MB 与省下 logits 相抵）；**远低于 ≥15% 整步门槛**。
- 归因段完成（editable 遮蔽/event 伪影）；pin 2×2 −6.8%（loss 四腿 bitwise）。披露：低 ρ 配置下机制无收益。

### 3.2 为什么停 / 当前
- 按 wave-1 门槛**不晋级**：判词="真实但太小"；unique+gather 属常规 memoization，不宣称 novelty；机制保留为 lane-local opt-in（`algorithm.<name>.teacher_dedup`，默认关、字节不变）。
- 当前：**DEFERRED**，无活跃工作；再开条件在 lane REPORT §8；lane 提交 `bfb3635`/`d6e3c9a`，无系统代码并入。

## 4. D3 — attention/mask 占比与形状构成

**研究问题**：attention+mask 占比与形状构成是否可解释、是否值得专用 kernel。

### 4.1 结果
- 真实 W0 step（B=8）：attention+mask ≈ **21.2ms / 595.9ms = 3.55%**（p50）；把两者**全部去掉**的 Amdahl 上限 = **+3.7%（步）/+1.4%（fully-online）**。
- 强基线核查：in-situ 即为 HF **compiled** FlexAttention（fused Triton fwd/bwd），非弱基线；eager 对照慢 ~30×，仅作对照不采用。

### 4.2 为什么停 / 当前
