# 交互（"打架"）分析：D1–D5 优化组合的风险地图 — 2026-10-15 · C0

- 请求：用户（两问：①"A 加速 5%、B 加速 10%，二者同步工作可能 <5 甚至负收益——分析会不会相互打架"；②"这几个不做的 agent 做出来的东西可能相互打架吗"——见 §6 专项）。
- 依据：已归档实测（D4×D1 2×2 等）+ 各成果的收益来源分解；逐项标注「已测 / 未测 / 预测」。本文件是分析，不改变任何判决。

## 0. 结论（TL;DR）

1. **已实测的组合问题只有一处**：D4×D1（2×2）W3 cell 组合数值门 FAIL（1.2475e-2@11 > 门 7.5e-3；bucket_on 两腿）——但 cache 腿字节惰性（floor probe 0.0、交互 bit-0）→ 归因是 **D1 regroup machinery 自身的数值缝**（后由 bug #01 证实），不是 A×B 相互放大。含义：组合会先被"其中一方的短板"拖死（数值门），轮不到速度问题。
2. **速度上最可能"1+1<2"且未测的两对**：**D4×D5**（同吃 producer/regen 供应链 → 替代风险；原计划"D4×D5 producer 重测"未执行）与 **D1×D5**（D1 只缩 train 段 → 进流水线按段权稀释；示意粗算 ≈ −7%，producer 成瓶颈时还可更小）。
3. 其余对（D1×D2、D2×D4、D2×D5）结构上近似加性（不同段/不同资源）；**数值风险几乎全部来自 D1**（D2/D4/D5 在证据上为字节惰性/调度级）。
4. **最"字面"的负收益已经发生过**：共卡竞争（事故 #1/#2/#4/#6：OOM、SIGTERM、contended 作废）——同步工作直接让结果不可用。
5. 通用数学（判断区间的框架）：互不相交的段 → 近似相加；乘性全覆盖 → `a+b−ab`（重叠损失=乘积项，轻）；同一段饱和 → ≈`max(a,b)`；关键路径翻转/数值门/资源冲突 → 可到 ≈0 或负。
6. **"不做的 agent"专项（§6）**：已停/未继续的 D2/D3/D5 之间**算法层无互撞证据**（D3 无产品改动；D2×D5 近加性）；真正可能 `<max` 的组合全部在**跨边界**——D5×D4（同吃 producer/recompute 供给，未测 P0）与 D5×D1（段权稀释 ≈−7% 示意）；资源层负收益已实际发生（事故 #1/#2/#4）。

## 3. 已发生的负收益形态（实例）

- **共卡竞争**（最直接）：事故 #1（D5×D2 共卡 OOM）、#2（D3×D2 OOM）、#4（D1 被外部 SIGTERM）、#6（check→launch 竞态 OOM）——"同步工作"直接毁掉结果或标 contended。
- **组合数值门**：D4×D1（W3）→ 组合暂禁（`d4xd1-003-c0`）。
- **伪收益陷阱**（别把假测量当收益）：D4 off vs cap10 的 wall 差=编译/冷启动顺序效应（非缓存收益）；D5 sim 预测 −14% vs 实测 −5.3%；D1 round-2 的 +19.0%/+24.7% 系 8 批 cell（不作主数字）。

## 4. 重测清单（组合部署前的前置）

- **P0**：D4×D5 producer 负载重测（原计划缺口）；D1×D5 在 S3 上的端到端 wall（含段权读法）。
- **P1**：D1×D2 同 step 相加性；D2×D4 正交确认（便宜）。
- 方法：A/B/A+B 同协议同卡（quiet）≥3 交替；**先过数值门**（含 D1 的组合当前全部被质量门锁住）；结论只报端到端关键路径，**不乘倍率**；段级 % 不得直接相加。

## 5. 部署建议（当前证据）

- 可单独用：D4（main、opt-in、字节惰性）；D5 S3（平台能力、实验态，store parity 已闭合）；D2（小、稳、lane-local）。
- 任何含 D1 的组合：**现在不可用**（质量门先行；bug #01 未结）。
- 组合声明前置：新预注册（含 A/B/A+B 矩阵与数值门）+ C0 独立重算收据；负结果照记。

## 6. "不做的 agent"产物互撞专项（D2/D3/D5；边界：D1 被锁）— 用户二次提问

问题原话："这几个不做的 agent 分析一下他们做出来的东西可能相互打架吗——A 可能加速 5%、B 加速 10%，但二者同步工作就是小于 5 甚至负收益"。判定范围为**已停/未继续的方向**（D2/D3/D5，无系统代码并入），并把被质量门锁住的 D1 regroup 作为边界参照。

### 6.1 停产方向各自留下了什么

| 方向 | 停止性质 | 留下的可组合产物 | 单独幅度（已测） |
|---|---|---|---|
| D2 teacher 去重 | STOP（真实但太小 → DEFERRED） | lane-local opt-in（默认关）；CPU oracle 12/12、loss 四腿 bitwise | pin 2×2 −6.8%；JetSpec mb4 −12.4ms/步（≈−3.0%）；DFly −33ms（≈−5.6%）；门槛 ≥15% |
| D3 attention/mask | CLOSED（瓶颈不存在） | **无产品改动**；仅 trace + Amdahl bound | 全去除上限 +3.7%（步）/+1.4%（在线）；实测占比 3.55% |
| D5 静态流水线 | HOLD（平台能力，收口） | lane 内 runner + store parity 工具 | S3 b8 −25.3%（adj −32.9%）；b32 −28.7% vs staged / −12.6% vs sync；sim −14% 被证伪 |
| （边界）D1 regroup | 工程 GO / 质量 FAIL + bug #01 → **组合全锁** | main 内 opt-in（默认关、禁用提示） | 步 1.135×（≈−12%）；质量出带 1.80–4.86× |

### 6.2 三人组内部互撞判定（回答原问题第一层）

- **D3 × 任何**：无产品改动 → 结构上不可能"打架"；只有信息价值（D1 之后 attention 占比更小）。
- **D2 × D5**：不同段——D2 省的是 step 内 teacher 投影计算，D5 改的是流水线相位/供给。结构上近加性到轻度重叠（`a+b−ab`，量级 <1%）；**未测但便宜可测**。风险级：低。
- **D2 × D3**：不可能（D3 无改动）。
- 结论：**三人组"互撞到 <min 甚至为负"的证据为零**；唯一能"打架"的位置全在边界之外 ↓

### 6.3 真正可能 "A+B < max(A,B)" 的候选（跨边界，未测）

1. **D5 × D4（P0，未测）**：同吃 feature 供给——S3 已把 regen/capture 移出串行路径并并行化；D4 cache 再消 recompute。若二者省的是同一段，组合 ≈`max(a,b)` 而非 `a+b`（替代）；且 cache 在训练进程内、S3 把 producer 移卡，存在语义/架构错位 + RAM 配额竞争（cache 预算 vs 流水线 buffer/store）。原计划"producer 负载重测"未执行（INTEGRATION §5 缺口）。
2. **D5 × D1（P0，未测）**：D1 只缩 train 段 → 收益进流水线按**段权稀释**（s3_b32 中 train 653s/1074s≈61% → 步级 −12% ≈ 流水线 −7%，示意粗算；producer 成瓶颈时更小）。D1 现被质量门锁 → 组合面当前不可及。
3. **D1 × 任何（已测一例）**：组合先被**数值门**杀——D4×D1 W3 cell F1-as-registered FAIL（1.2475e-2@11 > 7.5e-3）；cache 腿字节惰性（floor probe 0.0、交互 bit-0）证明不是 cache 参与放大，而是 D1 machinery 自身的数值缝（bug #01 跟进中）。"组合会被其中一方的短板拖死，轮不到速度问题"。
4. **资源层（已实际发生，最字面的负收益）**：事故 #1（D5×D2 共卡 OOM）、#2（D3×D2 共卡 OOM/contended）、#4（D1 被 SIGTERM，D2 同卡）——"同步工作"直接让结果作废；处置=租约卡+实测 quiet+单副本锁。

补充：INTEGRATION 曾记一条**正交互线索**——D5 v4 的 keep-oracle 可能需要"生成前已知 keep"的预测信号，若 D1 双轴组织能提供，则作为 D1×D5 条件组合讨论项（未批准；需共同监督位置）。即 D1×D5 目前=稀释风险 + 潜在条件协同，两者都需实测。

### 6.4 判定词与前置（当前证据）

- **D2/D3/D5 相互组合：无相互抵消证据**，但按 §2/§4 规则先测再合（D2×D5、D2×D4 从便宜的开始）。
- **D4×D5：在 P0 重测前不得叠加宣称**（替代 + 架构错位）。
- **含 D1 的组合面：冻结**（质量门 + bug #01；D1×D2 的数值风险也来自 D1 一侧）。
- 报数纪律：只报端到端关键路径；**不乘倍率、不把段级 % 相加**；A/B/A+B ≥3 交替、数值门先行；负结果照记。
