## 1. 问题（一句话）

## 2. 臂、因子与不变式（冻结）

- **2×2**（4 臂 × {W3, MIX} = **8 legs**；seed 42；每腿 1 warmup + 100 timed updates）：
  - bucket：`off`=canonical 默认路径；`on`=`train.regroup.mode=grid` + `sub_batch=2`（=集成 smoke 已验配置，k=4；不加别的数值开关）
  - cache：`off`=`train.online_feature_cache_gb=0`；`on`=`=16`（GiB；adaptive **不开**——D4 自适应 overlay 不属于本 2×2）；预期无 eviction（192/335 行 × ~6.7MB/行 ≪16GiB）
  - 模式：`train.feature_mode=online`；数据 = 与 wave-2 W3（192 行）/ MIX（335 行）相同行集（regen 协议一致；不读 feature store，特征 live 提取）
- **不变式**（违反 → 该腿作废重跑）：每格 4 腿同卡、同 seed、同行序、同 anchor 抽样（"同一冻结 anchor 表"）；代码冻结 = 窗口开启时 `research/rsi-c0` head（含 `4e1674e`+`1f8963e`；两机制 opt-in、默认 byte-identical），EXPERIMENTS 记录 exact SHA；每腿 rc=0、无 NaN、ckpt 自清、quiet-gate（util≤5%/free≥40GiB/disk≥10G）；cache_off 腿 counters = hits 0 / stores 0（隔离证据）。

## 3. 指标与判决（冻结；跑前写死）

- **F1 数值**：每腿整段 loss 轨迹 vs ref（cache_off×bucket_off）——任一记录步 loss_rel > **7.5e-3** → FAIL（canonical 自身 bf16 波动带；先例：vs-ref ≤9.5e-5，本门槛留有裕量）。parity 三批位（b0/50/100）grad/update：**要求交付**，捕获方法由 D1 addendum 声明；容差 grad_rel ≤6.0e-3、update_rel ≤1.0e-7（bf16 级）。若 D1 声明产品路径不可捕获 grad/update，退到"loss 轨迹 + 终值带"并在 EXPERIMENTS 显式标注口径缩窄（C0 事前接受，但倾向拿到）。
- **F2 缓存生效**：cache_on 腿 hits>0 且 stores>0，且 hits ≥ 0.5×行数（跨 epoch 复用真实发生；反空转）。
- **F3 内存保持**：peak(cache_on×bucket_on) ≤ **0.75 ×** peak(cache_on×bucket_off)（保留原 ≥25% 显存肢）；4 腿均无 OOM。
- **F4 速度方向**：两 cache 水平下 ratio=median step(canonical)/median step(regroup) ≥ **1.00**（缓存不得把 regroup 反转为劣势；数量本身描述性报告，不作 ≥15% 声称）。
- **F5 反事实（描述性）**：cache_on−cache_off 步时差按 bucket 两水平分列；命中差异（hit-pattern caveat 量化）。
- **判决映射**：全过 → **相容性成立**（wave-3/论文主轴=系统组合；harvest 文档给改写建议）；F3 败 → 交互冲突（降级单机制叙事）；F1 败 → 正确性阻断（cache×regroup 暂禁，另立项）；F2 败/腿废 → 无效窗口重跑（计入本租约；超限重新提案）。
