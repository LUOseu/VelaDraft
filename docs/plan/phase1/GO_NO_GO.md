  over its initialization - `R-20261014-11` (seed 42: AL 1.839 vs 1.003)

  and no second layout.

  preserved and blocks any exact serving claim.
- **G6 stays PARTIAL**: `R-20` landed length-bucketed timings at smoke scale
  (one bucket populated) - the 7B/8B shape profile is still missing.

Overall: **NO-GO stands** for the §7 formal matrix / any multi-node request

## What would flip a NO-GO (re-evaluation conditions)

- **G4:** >=2 seeds at the 2K protocol with the same-sign, separated
  trained-vs-init comparison (a small target is acceptable; the full recipe
  need not win). **Met 2026-10-14** (`R-11` + `R-23`; see the re-evaluation
  section).
- **G2:** paired same-semantics runs on >=2 layouts x 2 methods showing the
  ~20% full-training-cost reduction vs the tuned baseline; or one documented
  layout/store where a fixed-space cap makes otherwise-impossible training
  feasible, with the cost of the cap stated.
- **G5:** the token-exact gate closed (or the divergence root-caused and
  fixed) plus a real in-engine end-to-end timing at an intended config.
- **G6:** the 7B/8B small-sample shape profile and length-bucketed teacher
  timings, replacing [F] projections with [M] lows/highs.
- Re-evaluation procedure: update the table above with the new [M] evidence
  and route the decision again; do not reinterpret a partial gate as met.
